# Extracted Skill Rules

Source: `docs/CLI.md`

## Project Intelligence

`rayman project detect` prints the multi-language project index without writing state. Built-in adapters cover Rust, JavaScript/TypeScript, Python, C#, and Go. Missing language toolchains degrade to file/hash/import heuristics instead of blocking.

`rayman project index` writes `.RaymanCodingSkill/project/index.json` and refreshes the Context Index with adapter output.

`rayman impact --path <file>` reports directly changed files, affected modules, public API, likely tests, broad gates, docs/config risk, adapter confidence, and evidence.

`rayman regression plan --path <file>` turns impact output into minimal tests, language gates, broad gates, a review checklist, matched historical quality-pattern checks, and a risk recommendation block. The recommendation block includes `risk_level`, `risk_reasons`, and `recommended_focus`, scoring public API impact, quality-pattern matches, docs/config drift, obsolete-asset blockers, broad multi-file impact, and stale/degraded adapter evidence.

`rayman regression run --profile auto|quick|full|shared-parallel-full|parallel-full` executes repository regression gates and appends an immutable run record to `.RaymanCodingSkill/regression/history.jsonl`. `quick` runs formatting, CLI tests, agent eval, security audit, and repository audit. `full` runs formatting, clippy, all tests, agent eval, security audit, and audit serially. `shared-parallel-full` is generic for Cargo/Rust framework and opted-in user workspaces: it runs formatting and clippy with one TempManager-owned `CARGO_TARGET_DIR`, compiles tests once with `cargo test --workspace --all-targets --no-run --message-format=json`, parses the compiled test executables plus each artifact's `manifest_path`, runs those executables with bounded workers from their package manifest directories and explicit `RUST_TEST_THREADS`, then runs doc tests and the post-Cargo gates. `auto` records an `auto decision` step in regression history and selects the shared-build strategy when the workspace root has `Cargo.toml`. `parallel-full` runs formatting first, then runs clippy plus core/CLI/API tests concurrently with separate workspace-local Cargo target directories inside a TempManager run under `.RaymanCodingSkill/tmp/runs/`, then runs agent eval, security audit, and audit. When the whole profile succeeds, the managed Cargo target run directory is deleted automatically; when it fails, the managed run is marked failed, preserved for diagnosis, and the CLI prints the retained path plus `rayman temp cleanup --all-failed`. Use `shared-parallel-full` or `auto` when duplicate compilation should be avoided; use `parallel-full` when target lock contention is the main risk.

`rayman regression history --limit <n>` prints the newest regression run records first, including each step command, status, duration, exit code, and bounded stdout/stderr tails.

`rayman eval run --profile core|full` executes deterministic agent-behavior contracts as task-level fixtures against the quality-pattern engine. Each case reports the scenario text, required task contract, validation evidence, expected patterns, matched patterns, and missing patterns. The core profile covers audit-failure delivery, stale project context, tool-loop recovery, expert gate evidence, research autonomy, Codex host subagent ledger evidence, and Codex harness execution-contract evidence; the full profile adds managed temp, debug/release delivery, and obsolete-asset retirement cases.

`rayman security audit` checks LLM-specific security controls and Rust dependency policy. It blocks plaintext YAML `api_key` values, non-advisory auxiliary AI policy, missing env secret references for authenticated providers, untrusted providers receiving workspace data, missing `cargo-deny`, missing `deny.toml`, and failed `cargo deny check` results. Real secrets must live in environment variables such as `api_key_env`, not in repository YAML.

`rayman release evidence --label <label>` writes a local unsigned evidence bundle under `.RaymanCodingSkill/release/evidence/` unless `--no-write` or `--output` is used. The bundle includes the release binary hash, Cargo.lock hash, manifests, skill hash, self status, latest regression history record, dependency policy status, and provenance fields for Git status/commit/branch/dirty state, CI provider/run id, optional SBOM path, optional attestation path, signed status, and `provenance.completeness`. The completeness block records Git commit binding, clean worktree, CI binding, SBOM, attestation, signature, `external_distribution_ready`, and missing evidence names. Non-Git workspaces report `provenance.status=not_git` as a local-development warning by default; `--require-provenance` turns missing Git/SBOM/attestation/signature evidence into blocking required actions. Release evidence is partial when the latest regression record is missing or not passed, or when dependency policy is blocked.

`rayman self status` reports the running binary, canonical release binary, install source, installed PATH target, companion `提醒` reminder source/target, and skill hashes. `rayman self install` copies the canonical release binary and companion reminder to the installed PATH target directory, matching `rayman agent-skill sync`.

`rayman benchmark run --smoke` creates temporary Rust, JS/TS, Python, C#, and Go fixtures and verifies detect/index/impact smoke behavior.
